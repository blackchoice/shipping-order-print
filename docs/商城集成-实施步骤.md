### 方案 2：从商城后端 API 获取订单数据

如果订单数据通过 AJAX 获取，示例如下：

```javascript
async function printOrder(orderId) {
  try {
    // 1. 从商城后端获取订单详情
    const orderResp = await fetch(`/api/orders/${orderId}`);
    const order = await orderResp.json();
    
    // 2. 转换为打印格式
    const printData = {
      orderNo: order.orderNo,
      customerName: order.customer.name,
      date: order.orderDate,
      deliverer: order.deliverer || '',
      receiver: order.receiver || '',
      items: order.orderItems.map(item => ({
        productName: item.productName,
        unit: item.unit,
        quantity: item.quantity,
        unitPrice: item.unitPrice,
        remark: item.remark || ''
      }))
    };
    
    // 3. 调用打印
    const result = await ShippingPrintClient.printOrder(printData);
    
    if (result.success) {
      alert('打印成功');
    } else {
      alert('打印失败: ' + result.message);
    }
    
  } catch (error) {
    alert('打印失败: ' + error.message);
  }
}
```

### 方案 3：Vue.js 集成

如果商城使用 Vue.js：

```vue
<template>
  <div class="order-detail">
    <h2>订单详情</h2>
    <div>订单号：{{ order.orderNo }}</div>
    <div>客户：{{ order.customerName }}</div>
    
    <button @click="printOrder" :disabled="printing">
      {{ printing ? '打印中...' : '打印出货单' }}
    </button>
    <p v-if="printStatus" :class="printSuccess ? 'success' : 'error'">
      {{ printStatus }}
    </p>
  </div>
</template>

<script setup>
import { ref } from 'vue'

// 引入打印客户端（需要在 index.html 中引入 shipping-print-client.js）
const ShippingPrintClient = window.ShippingPrintClient

const order = ref({
  orderNo: 'XS-202607010206',
  customerName: '本部食堂',
  items: [
    { productName: '牛腩', unit: '公斤', quantity: 4, unitPrice: 70 }
  ]
})

const printing = ref(false)
const printStatus = ref('')
const printSuccess = ref(false)

async function printOrder() {
  printing.value = true
  printStatus.value = ''
  
  try {
    const result = await ShippingPrintClient.printOrder(order.value)
    
    printStatus.value = result.success
      ? `${result.message} → ${result.printerName}`
      : result.message
    printSuccess.value = result.success
    
  } catch (error) {
    printStatus.value = error.message
    printSuccess.value = false
  } finally {
    printing.value = false
  }
}
</script>

<style scoped>
.success { color: green; }
.error { color: red; }
</style>
```

### 方案 4：React 集成

如果商城使用 React：

```jsx
import { useState } from 'react'

// 在 public/index.html 中引入 shipping-print-client.js
const ShippingPrintClient = window.ShippingPrintClient

export default function OrderDetail({ order }) {
  const [printing, setPrinting] = useState(false)
  const [printStatus, setPrintStatus] = useState('')
  const [printSuccess, setPrintSuccess] = useState(false)
  
  async function handlePrint() {
    setPrinting(true)
    setPrintStatus('')
    
    try {
      const result = await ShippingPrintClient.printOrder(order)
      
      setPrintStatus(
        result.success
          ? `${result.message} → ${result.printerName}`
          : result.message
      )
      setPrintSuccess(result.success)
      
    } catch (error) {
      setPrintStatus(error.message)
      setPrintSuccess(false)
    } finally {
      setPrinting(false)
    }
  }
  
  return (
    <div>
      <h2>订单详情</h2>
      <div>订单号：{order.orderNo}</div>
      <div>客户：{order.customerName}</div>
      
      <button onClick={handlePrint} disabled={printing}>
        {printing ? '打印中...' : '打印出货单'}
      </button>
      
      {printStatus && (
        <p style={{ color: printSuccess ? 'green' : 'red' }}>
          {printStatus}
        </p>
      )}
    </div>
  )
}
```

### 方案 5：服务器端 Java 调用（备选）

如果商城后端是 Java（Spring Boot），可以直接调用打印服务 REST API：

```java
@Service
public class PrintService {
    
    private final RestTemplate restTemplate = new RestTemplate();
    
    // 本地打印服务地址（用户机器上）
    private static final String PRINT_SERVICE_URL = "http://localhost:8080";
    
    /**
     * 打印出货单
     * 注意：此方法需要在用户浏览器端调用，不能在服务器端调用
     * 因为打印机连接在用户本地机器上
     */
    public void printShippingOrder(Order order) {
        String url = PRINT_SERVICE_URL + "/api/print/shipping-order?printerName=NFCP%20DPK700";
        
        ShippingOrderPrintRequest request = new ShippingOrderPrintRequest();
        request.setCompanyTitle("怀化市兴隆农业开发有限公司出货单");
        request.setCustomerName(order.getCustomerName());
        request.setOrderNo(order.getOrderNo());
        request.setDate(order.getOrderDate());
        // ... 设置其他字段
        
        try {
            ResponseEntity<String> response = restTemplate.postForEntity(url, request, String.class);
            log.info("打印成功: {}", response.getBody());
        } catch (Exception e) {
            log.error("打印失败", e);
            throw new RuntimeException("打印失败: " + e.getMessage());
        }
    }
}
```

**重要提示**：服务器端调用只适用于打印服务也部署在服务器上的情况。如果打印机在用户本地，必须使用前端 JavaScript 调用。

## 故障排查

### 错误：本地打印服务未启动

**原因**：打印服务未运行或端口不是 8080

**解决**：
```powershell
cd C:\Users\Rachel\IdeaProjects\shipping-order-print\backend
.\mvnw.cmd spring-boot:run
```

### 错误：CORS 跨域错误

**原因**：后端未配置 CORS 或商城地址未添加到白名单

**解决**：编辑 `CorsConfig.java`，添加商城地址到 `allowedOrigins`

### 错误：未找到打印机

**原因**：打印机未正确安装或队列名称不匹配

**解决**：
```powershell
# 运行打印机设置脚本
.\scripts\setup-dpk700-printer.ps1

# 或手动检查
Get-Printer | Select-Object Name
```

### 错误：HTTPS 商城无法调用 HTTP 本地服务

**原因**：浏览器阻止混合内容

**解决**：为本地服务配置 HTTPS（参考 `browser-local-print-integration.md`）
